How to Reduce Blacklisting Risk
  • Set rDNS/PTR correctly — your IP must reverse-resolve to your mail hostname (e.g. mail.yourdomain.com). Set in your VPS control panel.
  • Configure SPF, DKIM & DMARC — use the Sending Domains tab to verify all three are passing.
  • Warm up gradually — enable Send Warmup in Settings → Advanced. Start at 50–100 emails/day and increase slowly over 2–4 weeks.
  • Rate-limit per provider — set conservative per-minute/per-hour limits in Settings → Advanced → Rate Limits, especially for Gmail and Outlook.
  • Keep your list clean — only send to opted-in recipients. Use a suppression file (Settings → Advanced) to skip hard bounces.
  • Include an unsubscribe link — required by Gmail/Yahoo since 2024. Set unsubscribeBaseUrl in Settings → General.
  • Monitor bounces — any 550 5.7.1 blocked rejection means the IP is listed. Stop sending and delist before resuming.
  • Use a dedicated IP per domain — mixing domains on one IP means one bad domain poisons the IP for all others.
